# paystream

Type in a salary and watch it arrive, second by second — with federal tax, state tax, Social
Security and Medicare taking their share in streams beside it.

Everything runs in your browser. Nothing you type is sent anywhere.

**Status:** being built — a placeholder is live at https://paystream.bitcopia.workers.dev. See
[`docs/PRODUCT_BRIEF.md`](docs/PRODUCT_BRIEF.md) and the phased plan in
[`docs/ENGINEERING_SPEC.md`](docs/ENGINEERING_SPEC.md).

```sh
npm install
npm run dev      # http://localhost:5173
npm run check    # typecheck, lint, format, tests, build
```

Tax figures are estimates for illustration, not tax advice.
